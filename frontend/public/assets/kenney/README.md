# Roguelike Indoor pack

Creator: Kenney (https://kenney.nl)

License: CC0 1.0. The original license is included in LICENSE.txt.

Source: https://kenney.nl/assets/roguelike-indoors

Downloaded from the creator's OpenGameArt upload:
https://opengameart.org/content/roguelike-indoor-pack

`indoors.png` is the original `Spritesheet/roguelikeIndoor_transparent.png`.
Tiles are 16×16 with one pixel of spacing. The school map uses desks,
chairs, plants, bookcases, cabinets and sofas from this sheet.
School-specific objects (computers, toilets, lockers, lab benches, etc.)
and the floor/wall textures are drawn in project code.
