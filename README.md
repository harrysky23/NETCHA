# NETCHACAMELEON

**CHROMIMIC**이라는 타이틀의 2D 탑다운 온라인 위장 숨바꼭질 게임입니다. 모든 플레이어가 같은 16×16 사람 실루엣을 사용하며 기본 색은 흰색입니다. 게임 안에서 `C`를 눌러 칠하고, 학교 안에서 숨거나 찾아냅니다.

게임 화면은 브라우저 전체를 채우며, 점수판은 맵 오른쪽 위, 전체 채팅은 오른쪽 아래에 표시됩니다. 학교는 64×48 타일(2048×1536px)이며 교실 두 곳, 복도, 도서실, 컴퓨터실, 과학실, 화장실, 교무실과 114개의 오브젝트로 구성했습니다. 방 사이의 벽과 화장실 칸막이도 이동·사격을 막습니다.

## 실행

필요 환경: Node.js 22.22.2 이상 및 Python 3.12 이상.

### 백엔드 터미널

```sh
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

서버는 `http://localhost:8001`에서 실행됩니다. macOS zsh에서도 위 명령을 그대로 사용할 수 있습니다.

### 프런트엔드 터미널

```sh
cd frontend
npm install
npm run dev
```

`http://localhost:5174`를 브라우저에서 엽니다. 다른 프로젝트와 충돌하지 않도록 프런트엔드 포트는 5174로 고정했습니다. 프런트엔드 개발 서버가 `/api` 요청과 `/ws` WebSocket 연결을 로컬 FastAPI 서버로 전달합니다. 다른 기기에서 같은 LAN으로 접속하려면 프런트엔드 주소를 공유하고, 방 코드를 입력하면 됩니다. 방장은 `localhost`가 아닌 자신의 컴퓨터 LAN 주소를 공유해야 합니다.

## 한 판의 흐름

1. 이름을 입력해 방을 만들거나 5자리 코드로 입장합니다. 한 방에 2~8명이 참여합니다. 혼자 있는 방에서는 **혼자 테스트 시작**으로 대기·시간 제한 없이 이동, 충돌, C키 색칠을 확인하고 로비로 돌아올 수 있습니다.
2. 방장이 시작하면 술래가 무작위로 정해집니다. 30초 동안 도망자가 숨고 위장하며, 술래 화면에는 대기 안내가 표시됩니다.
3. 최대 3분 동안 술래가 마우스 방향으로 단발 사격합니다. 사격 간격은 1초이며 탄약 제한은 없습니다. 벽·가구가 탄환을 막고, 도망자는 한 번 맞으면 탈락합니다.
4. 생존 도망자는 술래 화면 안에 잡히면 점수를 얻습니다. 화면 안에서는 거리 128px 초과 시 초당 1점, 128px 이내 3점, 64px 이내 10점, 32px 이내 30점을 얻습니다. 모든 플레이어가 실시간 점수판을 봅니다.
5. 도망자는 서로의 시점을 관전할 수 있습니다. 관전 중 자신의 캐릭터는 움직이지 않으며 계속 피격될 수 있습니다. 채팅은 대기 중과 탈락 후에도 방 전체에 전달됩니다.
6. 승패 결과를 표시한 뒤 로비로 돌아옵니다. 다음 판은 술래를 다시 무작위로 정합니다.

조작: `WASD` 이동, `C` 그리기 모드 켜기/끄기, 그리드에서 클릭·드래그 색칠, 술래는 마우스를 조준해 클릭 사격. 색칠 중 `I` 또는 스포이드 버튼으로 맵이나 캐릭터의 색을 가져옵니다. 그리드에서는 `Alt+클릭`도 지원합니다. 기본 8색 외에 채집한 정확한 RGB 색을 캐릭터 팔레트에 보관하며 최대 64색을 쓸 수 있습니다. 흰색 초기화는 채집한 색도 비웁니다.

## 구조

```text
frontend/src/
  components/   시작 화면, 로비, 채팅, 점수판/결과
  data/         공통 팔레트와 16×16 캐릭터 마스크
  game/         Phaser 학교 맵, 카메라, 캐릭터, 이동/충돌
  network/      WebSocket 메시지 타입과 React 방 연결 훅
  types/        캐릭터 데이터 및 픽셀 페인팅 함수
backend/app/
  main.py       FastAPI HTTP/WebSocket 진입점
  world.py      방, 라운드, 이동, 충돌, 사격, 점수, 채팅 규칙
shared/map.json 프런트엔드와 서버가 공유하는 방·벽·가구·생성 위치
shared/character.json 공통 사람 실루엣, 기본 팔레트와 흰색 기본값
```

React는 화면, 로비 폼, 색칠 UI와 연결 수명을 관리합니다. Phaser는 맵 렌더링, 카메라, 키 입력 및 화면상 캐릭터 표현을 담당합니다. FastAPI 서버는 방 상태, 이동과 충돌, 사격 결과, 점수 및 채팅을 권위 있게 처리합니다. 상대 위치는 시야 규칙에 따라 가리고, 숨는 시간에는 술래에게 다른 플레이어의 위치를 보내지 않습니다.

화면 비율에 따라 Phaser 카메라가 보고 있는 월드 범위를 서버에도 전송합니다. 서버는 최대 800×600px로 제한하고 실제 시야 범위에 맞춰 점수와 사격을 판정합니다.

## 에셋과 확인 방법

가구는 [Kenney Roguelike Indoors](https://kenney.nl/assets/roguelike-indoors)의 CC0 에셋을 사용합니다. 원본 PNG와 라이선스, 다운로드 출처는 `frontend/public/assets/kenney/`에 포함했습니다. 컴퓨터·화장실·사물함·실험대와 바닥·벽은 프로젝트에서 직접 그립니다.

```sh
cd frontend
npm test
npm run build
```

백엔드 테스트는 `backend` 폴더에서 가상환경을 활성화한 뒤 `python -m unittest discover -s tests`로 실행합니다. 사람 실루엣과 흰색 기본값, 스포이드 팔레트 검증, 내부 벽 충돌·사격 차단, 화면 비율별 점수, 각 방으로의 통로를 확인합니다.

## 현재 범위와 제한

- 방 상태는 Python 프로세스 메모리에만 있습니다. 서버 재시작 시 방과 점수가 사라집니다.
- 인증은 임의 토큰을 사용하는 임시 방 세션이며 계정·DB·지속 저장은 없습니다.
- 공개 배포, TLS, 외부 매치메이킹은 설정하지 않았습니다. 현재 로컬 개발 서버를 통한 친구 초대용 프로토타입입니다.
- 화면 렌더링은 클라이언트 예측을 사용하고 서버가 충돌·점수·피격을 판정합니다. 운영 환경 수준의 치트 방지나 지연 보정은 포함하지 않습니다.
- 실제 브라우저에서 2대 기기 접속, 키보드·드래그·사격·충돌을 최종 확인해야 합니다.
